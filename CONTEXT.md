# Kollect

A browser extension for keeping track of the manga, manhwa and manhua you read on reading websites.

## Manga

**Shared manga list**:
Every manga anyone has added to Kollect, one entry per series. The Add Manga search looks in it.
_Avoid_: catalogue, manga database

**Library**:
The manga one user has saved, each on one progress page.
_Avoid_: collection, list

**Private manga**:
A manga in the shared manga list that is only on own websites. It doesn't show in other people's Add Manga search until someone adds it from a built-in website.
_Avoid_: hidden manga

**Alternative title**:
Another name a manga is known by, such as a translated title. Search and matching check it as well as the main title.
_Avoid_: alt name, other title

**Own title**:
The title one user gave a manga, which only they see in their library. Everyone else sees the shared title.
_Avoid_: custom title, nickname

**Current chapter**:
The furthest chapter you've read past your Scroll Threshold, or the one you typed in the check box.
_Avoid_: last chapter, latest chapter (that's the newest chapter the series has)

**Reading history**:
Every chapter you've read of a manga, on any website.

## Reading websites

**Built-in website**:
A reading website every user gets, with rules Kollect ships.
_Avoid_: supported site, default site

**Own website**:
A reading website one user added from a page. Only they see it.
_Avoid_: custom site, user site

## Adding

**Add**:
Saving the manga on the page you're on to your library, from the Kollect button, the right-click menu or Alt+Shift+K.
_Avoid_: save, track, import

**Check box**:
The box that opens on Add when Kollect needs you to confirm or fill in the website name, title or chapter.
_Avoid_: confirm dialog, popup
